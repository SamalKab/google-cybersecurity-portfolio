# Risk Assessment

## Overview
This project is part of the Google Cybersecurity Professional Certificate.

The goal of this activity was to identify security risks, evaluate their likelihood and severity, and prioritize risks based on their potential impact.

## Skills Demonstrated
- Risk assessment
- Asset identification
- Risk analysis
- Likelihood and severity evaluation
- Risk prioritization
- Security recommendations

## Assessment Process
The assessment included:
- Identifying important assets
- Identifying potential risks and threats
- Evaluating likelihood and severity
- Assigning priority levels for mitigation

## Risk Assessment Categories

| Category | Description |
|---|---|
| Asset | Resource that needs protection |
| Risk | Potential security threat |
| Likelihood | Probability that a risk will occur |
| Severity | Impact of the risk if it occurs |
| Priority | Urgency level for addressing the risk |
