# PASTA Threat Model

This project is based on the Google Cybersecurity Professional Certificate.

I used the PASTA (Process of Attack Simulation and Threat Analysis) framework to analyze security risks for a mobile sneaker marketplace application.

## Assessment includes:
- Business objectives
- Technology requirements
- Threat identification
- Vulnerability analysis
- Security controls

## Security Controls:
- Multi-factor authentication (MFA)
- Prepared statements to prevent SQL injection
- Encryption of sensitive data
- Role-based access control (RBAC)
