# Incident Handler's Journal

## Overview

This incident handler's journal was completed as part of the Google Cybersecurity Professional Certificate. It documents my practice with incident investigation, incident response, security tools, and security event analysis.

## Incident Response Activities

The journal includes four entries covering:

- Documenting a security incident
- Investigating network traffic
- Exploring Suricata for network threat detection
- Investigating failed SSH login attempts using Wazuh

## Incident Investigation

The journal uses the **5 W's** framework to document security incidents:

- Who
- What
- When
- Where
- Why

These entries helped me practice identifying relevant information during the Detection and Analysis phase of the NIST Incident Response Lifecycle.

## Cybersecurity Tools

### Suricata

Suricata was used to learn about network-based threat detection, signatures, and security event alerts.

### Wazuh

Wazuh was used to search and analyze security event data and investigate failed SSH login attempts involving the root account.

## Key Skills

- Incident documentation
- The 5 W's of incident investigation
- Network traffic analysis
- Log analysis
- Security event investigation
- Signature-based detection
- SIEM and security monitoring
- NIST Incident Response Lifecycle

## Reflection

Completing this journal helped me understand how security analysts document incidents and investigate suspicious activity. I also gained practical experience with network traffic, security logs, detection tools, and incident response processes.
