# Linux File Permissions Management

## Project Description

This project demonstrates my ability to use Linux commands to manage file permissions. I analyzed existing permissions, identified incorrect access settings, and used Linux commands such as ls -la and chmod to update authorization.

## Skills Demonstrated

- Linux command line
- File permissions
- Access control
- chmod command
- Security authorization management

## Commands Used

### ls -la

Displays all files and directories, including hidden files, along with their permissions and ownership information.

### chmod

Used to modify file and directory permissions to ensure appropriate access control.

## Summary

In this project, I used Linux commands to analyze and manage file permissions. I reviewed permissions, updated access settings, and protected files and directories from unauthorized access. This activity helped me understand how security professionals use Linux to manage authorization and maintain system security.
