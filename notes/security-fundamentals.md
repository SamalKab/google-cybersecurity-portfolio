# CIA Triad

The CIA Triad is a foundational security model used to protect information and systems.

## Confidentiality

Confidentiality ensures that information is accessible only to authorized users.

Examples:
- Access controls
- Authentication
- Encryption

## Integrity

Integrity ensures that data remains accurate, consistent, and trustworthy.

Security measures:
- Hashing
- File integrity monitoring
- Change management

## Availability

Availability ensures that systems, services, and data are accessible when needed.

Security measures:
- Backups
- Disaster recovery plans
- System maintenance

# Security Frameworks

Security frameworks are guidelines used by organizations to manage cybersecurity risks and protect data and privacy.

Examples:
- NIST Cybersecurity Framework (CSF)
- Security controls
- Risk management processes

---

# Security Posture

Security posture is an organization's ability to manage its defense of critical assets and protect against cybersecurity threats.

A strong security posture includes:
- Identifying risks
- Implementing security controls
- Monitoring systems
- Improving response strategies
